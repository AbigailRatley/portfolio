Roll the Tapes

In my university degree, one of our modules included hosting a showcase event. We planned everything from date, location, theme, catering, props, invites etc. We decided on a 70's themed gameshow style event, to turn our film based showcase into somehting more interactive. I decided to create a website for this event as further advertsing, so used the colour scheme and font decisions made by the promotion and marketing team to design and develop this website.
I originally had a countdown in the hero section of the home page that I coded using JavaScript but after the event I edited a short video to replace this so the website was still visually interesting and dynamic.
I used HTML and CSS to create this website and it was the first website I have created using this combination. I used containers for the different sections, both vertically and horizontally; ensured the typographic heirarchy was correct to draw focus to the crucial elements; and used JavaScript to create the image carosel.
